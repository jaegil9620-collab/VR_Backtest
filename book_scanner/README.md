# 책 스캔 · 요약 프로그램

책 페이지 이미지(또는 PDF)를 Claude 로 읽어서 **장별 Markdown(본문·표) + 잘라낸 그림 + 요약(SUMMARY.md)** 으로 만듭니다.
《라오어의 미국주식 밸류 리밸런싱》을 손으로 변환했던 과정을 프로그램으로 만든 것이고, 다른 투자 책의
백테스트·자동매매 설계 자료를 만드는 데 다시 쓰려는 목적입니다.

## 처음 한 번

1. Python 3.10 이상 설치 (이미 VR 백테스터를 쓰고 있으면 됨).
2. Claude API 키 만들기: <https://console.anthropic.com> → API Keys → Create Key. Billing 에서 몇 달러 충전.
3. `run.bat` 더블클릭 → 처음엔 필요한 패키지를 설치하고 창이 열립니다.
4. 창 맨 위 **API 키** 칸에 키를 붙여 넣고 [저장]. (키는 이 폴더의 `settings.json` 에만 저장되고 GitHub 에는 올라가지 않습니다.)

> 회사·집 네트워크가 `api.anthropic.com` 을 막으면 연결 오류가 납니다. 그럴 땐 휴대폰 핫스팟으로 하세요.

## 사용 순서

| 탭 | 하는 일 |
|---|---|
| ① 화면 캡처 | 브라우저·전자책 뷰어에 책을 띄우고 [영역 고르기]로 페이지 부분을 끌어서 지정 → [캡처 시작]. 5초 안에 책 화면을 한 번 클릭해 두면, 프로그램이 캡처 → 다음 페이지 키 → 캡처를 반복해 `page_0001.png …` 로 저장합니다(찍을 때마다 '띵' 소리, 화면 구석 표시창에 진행 상황). Esc 로 멈추고, 화면이 더 안 바뀌면 자동으로 끝납니다. 뷰어가 키를 안 받으면 넘김 키를 **직접 넘기기**로 바꾸세요: 내가 페이지를 넘길 때마다 화면이 멈추면 자동으로 찍습니다. |
| ② Markdown 변환 | 이미지 폴더(①의 결과나 기존 스크린샷/스캔 파일) 또는 PDF 를 골라 [변환 시작]. 결과 폴더에 `00_…md, 01_…md`(장별), `images/`(그림), `README.md`(목차), `_all.md`(전체)가 생깁니다. |
| ③ 요약 | 변환 폴더를 골라 [요약 만들기] → `SUMMARY.md`: 책 개요, 장별 요약표, **자동매매 설계용 핵심 규칙**, 백테스트 검증용 숫자, 한계, 빠진 부분. "요약 관점"에 원하는 초점을 적을 수 있습니다. |

### 알아 두면 좋은 것
- **비용**: [비용 미리 보기]가 대략 알려 줍니다. Opus 5.5 기준 쪽당 약 7센트(펼침면 75장 ≈ 150쪽 ≈ $10 안팎), Sonnet 5.5 는 절반. 요약은 책 한 권에 $1 안팎.
- **다시 돌려도 무료**: 한 번 인식한 쪽은 결과 폴더의 `_cache/` 에 저장돼서, 장 나누기 설정만 바꿔 다시 변환하면 API 를 다시 부르지 않습니다. 특정 쪽만 다시 인식하려면 그 쪽의 캐시 파일을 지우면 됩니다 (`pages.json` 에서 번호 확인).
- **펼침면**: 한 장에 두 쪽이 있는 스크린샷은 자동으로 반씩 나눠 읽습니다(글자가 더 정확해짐).
- **그림 위치**: Claude 가 알려 준 위치로 자르기 때문에 가끔 조금 어긋날 수 있습니다. 어긋난 그림은 원본에서 직접 잘라 `images/` 의 같은 이름으로 덮어쓰면 됩니다.
- 캡처는 **본인이 산 책을 개인 공부용으로** 정리할 때 쓰세요. 일부 뷰어는 화면 캡처를 막아 검은 화면이 찍힐 수 있습니다.
- 고급 설정: `settings.json` 의 `ocr_effort`(기본 low), `summary_effort`(기본 high)로 Claude 가 얼마나 공들여 생각할지 바꿀 수 있습니다.

## 파일 구성

```
app.py              화면(UI)
scanner/capture.py  화면 영역 고르기, 자동 캡처·페이지 넘김 (Windows)
scanner/pipeline.py 이미지·PDF 읽기, 펼침면 나누기, 캐시, 그림 자르기, 장 파일 나누기
scanner/claude.py   Claude API 호출, 비용 계산
scanner/prompts.py  Claude 에게 주는 지시문 (변환 규칙, 요약 형식) ← 결과 형식을 바꾸고 싶으면 여기
tests/              API 없이 돌아가는 시험 (python -m pytest tests)
```
